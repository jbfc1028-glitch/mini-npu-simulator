
# Mini NPU Simulator

## 1. 프로젝트 소개

Python으로 NPU의 기본 연산인 MAC(Multiply-Accumulate)을 구현한 시뮬레이터입니다.

입력 패턴과 두 필터의 MAC 점수를 계산하여 어느 필터와 더 유사한지 판정합니다.

## 2. 개발 환경

- Python 3.8 이상
- 외부 라이브러리 사용하지 않음
- Python 표준 라이브러리 json, time 사용

## 3. 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python main.py
```

실행 후 메뉴를 선택합니다.

- 1번: 3×3 필터와 패턴 직접 입력
- 2번: data.json 자동 테스트
- 3번: MAC 성능 비교
- 0번: 프로그램 종료

## 4. 주요 기능

### MAC 연산

입력 패턴과 필터의 같은 위치에 있는 숫자를 곱하고 모두 더합니다.

MAC = Σ(입력값 × 필터값)

이중 for 반복문을 사용하여 구현했습니다.

### 판정 방식

두 필터의 MAC 점수를 비교합니다.

- Cross 점수가 높으면 Cross
- X 점수가 높으면 X
- 점수 차이가 1e-9보다 작으면 UNDECIDED

직접 입력 모드에서는 Cross와 X 대신 A와 B로 출력합니다.

### JSON 테스트

data.json에서 필터와 입력 패턴을 불러옵니다.

패턴 크기에 맞는 필터를 선택하고 MAC 점수를 계산합니다.

기대 정답과 비교하여 PASS 또는 FAIL을 출력합니다.

### 성능 비교

3×3, 5×5, 13×13, 25×25 크기의 행렬을 각각 100회 연산합니다.

각 크기별 MAC 연산 횟수와 평균 실행 시간을 밀리초(ms) 단위로 출력합니다.

## 6. 실패 원인 분석

1. 일부 테스트에서는 두 필터의 MAC 점수가 거의 동일하게 계산됩니다.
2. size_5_1에서는 Cross와 X의 점수가 모두 약 0.9입니다.
3. 따라서 점수 차이가 epsilon보다 작아 UNDECIDED로 판정됩니다.
4. 하지만 기대 정답은 X이므로 FAIL이 발생합니다.
5. size_13_2에서는 두 점수가 모두 약 7.5입니다.
6. 이 경우에도 점수 차이가 epsilon보다 작아 UNDECIDED가 됩니다.
7. 기대 정답은 Cross이므로 FAIL로 처리됩니다.
8. size_25_1에서도 두 점수가 모두 약 4.9로 계산됩니다.
9. 기대 정답은 X이지만 UNDECIDED로 판정되어 FAIL이 발생합니다.
10. Python의 부동소수점 연산에서는 미세한 오차가 발생할 수 있습니다.
11. 이를 처리하기 위해 abs(score_a - score_b) < 1e-9 조건을 사용했습니다.
12. JSON 데이터의 크기나 숫자 형식이 잘못된 경우에도 FAIL로 처리하도록 검증 함수를 구현했습니다.
13. 이러한 실패는 반드시 코드 오류를 의미하지 않으며 필터의 구분 능력과 판정 기준에 영향을 받습니다.

## 7. 시간 복잡도

MAC 연산은 N×N 행렬의 모든 원소를 한 번씩 확인합니다.

이중 for 반복문을 사용하므로 연산 횟수는 N²입니다.

따라서 시간 복잡도는 O(N²)입니다.

행렬 크기가 커질수록 필요한 연산 횟수가 제곱에 비례하여 증가합니다.
